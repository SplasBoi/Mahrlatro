# Mahrlatro - A mod for Balatro

<img src="media/thumbnail.jpg">

>[!NOTE]
> This mod is only made to run on PC and Mac. IOS/Andriod is not supported.

## Dependencies
- [Lovely](https://github.com/ethangreen-dev/lovely-injector) (0.6.7 minimum)
- [Steamodded](https://github.com/Steamodded/smods) (26.829.0 minimum)

## Installation
- Download the [latest release](https://github.com/SplasBoi/Mahrlatro/archive/refs/heads/main.zip).
- Extract the contents to your Balatro mod folder:
    - **Windows:** `%appdata%/Balatro/Mods`

    - **MacOS:** `~/Library/Application Support/Balatro/Mods`

    - **Linux:** `~/.local/share/Balatro/Mods`
